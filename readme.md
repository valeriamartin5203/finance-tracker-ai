# 🌍 FinanceTracker AI

**Aplicación web de finanzas personales con análisis inteligente**

---

## 📌 Descripción

FinanceTracker AI es una aplicación web diseñada para ayudar a los usuarios a gestionar sus finanzas personales de manera sencilla e intuitiva.
Permite registrar ingresos y gastos, visualizar el comportamiento financiero mediante gráficas y recibir recomendaciones personalizadas utilizando inteligencia artificial.

El sistema está pensado para ser utilizado por personas de diferentes países, integrando soporte para múltiples monedas e idiomas.

---

## 🎯 Objetivo del proyecto

Desarrollar una herramienta digital que facilite el control financiero personal, combinando funcionalidades tradicionales con el uso de inteligencia artificial para mejorar la toma de decisiones.

---

## 🚀 Características principales

* Registro de ingresos y gastos
* Clasificación por categorías (comida, transporte, entretenimiento, etc.)
* Visualización de datos mediante gráficas
* Soporte multimoneda
* Interfaz intuitiva y fácil de usar
* Generación de recomendaciones mediante IA

---

## 🧠 Funcionalidades de Inteligencia Artificial

El sistema integra IA para mejorar la experiencia del usuario:

* **Clasificación automática de gastos**
  Detecta la categoría de un gasto a partir de su descripción

* **Análisis financiero**
  Identifica patrones de consumo

* **Recomendaciones personalizadas**
  Sugiere acciones para mejorar el ahorro

## ⚙️ Instalación y ejecución

1. Clonar el repositorio:

```bash
git clone https://github.com/tu-usuario/finance-tracker-ai.git
```

2. Entrar a la carpeta del proyecto:

```bash
cd finance-tracker-ai
```

3. Instalar dependencias:

```bash
npm install
```

4. Ejecutar el servidor:

```bash
npm start
```

5. Abrir en el navegador:

```
http://localhost:3000
```
